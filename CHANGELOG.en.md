# Changelog

[简体中文](CHANGELOG.md)

## 0.3.2 - 2026-08-25

- Added an optional high-density 60–120s Douyin pacing preset: conflict by 3 seconds, an immediate objective by 10 seconds, and 18–24 effective beats per 90 seconds.
- Added 15–25-second micro-task loops plus multiple dialogue turns and 4–7 visible actions/reactions per roughly 30-second voiced scene.
- Required one macro goal across the film and a causal bridge for every scene change, while stating that effective beats do not equal cuts or generation requests.
- Added a Wan 3 reference-driven multi-character native-dialogue route with one-to-one image/video/voice binding, full-block performance, clean native audio, R2V/frame-lock exclusivity, and input-video duration budgeting.
- Integrated the preset into both Skill languages, story/directing references, and production briefs, with a new evaluation scenario and automated regression test.

## 0.3.1 - 2026-08-25

- Redesigned the GitHub README hero, quick start, workflow, model routing, validation, and documentation navigation.
- Added a direct comparison with common alternatives and eight built-in capability modules such as Story Doctor, Visual Director, and Continuity Keeper.
- Added Codex, Claude Code, WorkBuddy, and Agent Skills compatibility keywords with explicit validation and installation boundaries.
- Kept the Chinese default and English mirror synchronized.

## 0.3.0 - 2026-08-25

- Adopted the Dramake name and one-Skill positioning: a beginner can start from text and connect a director-level short-drama pipeline.
- Made Chinese the default and added synchronized English mirrors for the README, Skill, references, templates, examples, observations, contributing guide, and issue templates.
- Added directorial intention, value turn, camera contract, motivated movement, internal-shot budget, pacing curve, and scene-boundary rules.
- Added identity, wardrobe, material, voice, and reference-authority locks to stop tail-frame drift, cross-bound voices, and unlimited output-sourced chains.
- Strengthened native dialogue, reference audio, external dubbing, hybrid post, J/L cuts, ambience, and human blind A/B voice QA.
- Added separate landscape/portrait composition, motion, safe-area, and acceptance planning instead of blind cropping.
- Added shot, voice, and audio-continuity templates plus cross-file validation for unaccepted parents, sparse long blocks, shots beyond duration, unknown voices, and invalid spend plans.
- Expanded to 14 scenario evaluations and stated that instruction coverage is not generated-video quality.

## 0.2.0 - 2026-08-25

- Generalized the skill from pet-focused video to live-action, pet, fantasy, animation, branded, UGC, anthology, and serialized productions.
- Added dual-timescale generation blocks and edit beats.
- Separated model, provider, quality tier, and spend authorization.
- Added approved-batch and autopilot-with-cap execution modes plus cost per accepted second.
- Added editable model cards, project canon state, provider-adapter boundaries, content profiles, audio boundary state, and five-way repair dispositions.
- Kept all operating instructions independently written and execution-surface neutral.
